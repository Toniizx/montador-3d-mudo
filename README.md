# Devon 3D · Guia Completo de Montagem

Guia interativo 3D para montar o criado-mudo Devon (Tok&Stok), com instruções em português, fotos do manual e catálogo de ferragens.

## Abrir

O site é estático. Abra `index.html` no navegador. Os arquivos também são adequados para hospedagem no GitHub Pages. No iPhone, após publicar, abra o endereço pelo Safari.

## Publicar pelo GitHub Pages

1. No repositório, abra **Settings → Pages → Build and deployment**.
2. Em **Source**, escolha **Deploy from a branch**; em **Branch**, selecione `main` e a pasta `/ (root)`. Clique em **Save**.
3. Em 1–2 minutos o link aparece em **Settings → Pages**, no formato `https://USUARIO.github.io/montador-3d-mudo/`.

Observação: o endereço só existirá após a publicação. O projeto usa caminhos relativos para funcionar tanto na raiz quanto em subpastas.

## No iPhone

No Safari, abra o link do GitHub Pages, gire o modelo com um dedo, amplie/reduza com dois dedos e use os controles da interface. Você pode usar **Compartilhar → Adicionar à Tela de Início**.

## Cuidados

As animações são ilustrativas e não substituem as posições de furo do manual. Confirme sempre o código da peça, quantidade e ferragem antes de apertar. A parafusadeira elétrica não é exigida pelo manual; se optar por usá-la, mantenha torque baixo e finalize à mão.
